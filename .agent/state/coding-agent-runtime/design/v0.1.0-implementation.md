# Verified v0.1.0 Implementation

## Status

`agentx` is implemented as a Go 1.25 single-binary CLI named `ax`, version `0.1.0`.

The verified implementation described here includes commit `076102c`.

## Implemented runtime and drivers

- Orthogonal runtime/driver structure; no giant all-capabilities adapter.
- Agent Registry contains only Claude, Codex, Gemini, OpenCode, and Pi. CASR is not modeled as an Agent.
- Package Registry independently contains those five Agent packages plus CASR, so `ax install casr` remains supported without coupling package installation to Agent discovery.
- `PackageDriver`:
  - npm install plans for Claude Code, Codex CLI, Gemini CLI, OpenCode, and Pi Coding Agent.
  - Official installer plan for CASR.
- `AuthDriver`:
  - Starts each Agent's native subscription-account OAuth login flow; `agentx` does not record subscriptions or store/proxy credentials.
  - Claude, Codex, and OpenCode use their native login commands.
  - Gemini and Pi launch their interactive clients and prompt the user to run `/auth` and `/login`, respectively.
- `LaunchDriver`:
  - Launches native Agent CLIs.
  - Maps `--model` to the native invocation.
  - Passes arguments following `--` through to the native CLI.
- `ModelDriver`:
  - Codex reads its native `models_cache.json`.
  - OpenCode invokes `opencode models`.
  - Pi invokes `pi --list-models`.
  - Claude and Gemini advertise model selection only; `agentx` does not fabricate model-list support for them.
- `SessionDriver`:
  - Transparently delegates CASR `providers`, `list`, `info`, and `resume` operations.
- Agent location commands: `ax list` and `ax which`.
- Global `--json` and `--yaml` output flags define the structured result protocol for `list`, `models`, and `install`/`auth`/`run` dry-run plans. YAML uses `gopkg.in/yaml.v3` and covers the same AgentX-owned results as JSON.
- Actual external process stdout/stderr remains native passthrough output. Debug logs remain JSON and are not affected by result-format flags.
- External command calls emit debug JSON containing the raw input, raw output, and raw error.

## Preserved boundaries

- No user-facing Profile schema.
- No credential custody.
- Native CLIs, model sources, and CASR remain the delegated sources of truth.
- CASR's package lifecycle and session role are independent of Agent Registry membership.
